Top-down 3D mining game

押して、運んで、鉱山を育てる。

Ore Dozerは、ブルドーザーで鉱石を押し集め、 トロッコへつながる採掘ラインを育てる見下ろし型3Dゲームです。 設備とモンスターを強化しながら、 手作業の鉱山をにぎやかな生産ラインへ成長させよう。

Mining and logistics

採掘ラインを、自分の手で動かす。

次々に現れる鉱石をブルドーザーのバケットでまとめ、 崩さないように納品エリアまで運びます。 納品された鉱石はトロッコが回収し、 プレイヤーが受け取れるGoldへ変わります。

  • 見下ろし型3D 鉱石の動きと生産ラインの成長を、 マップ上で見ながら遊べます。
  • 指一本の基本操作 ブルドーザーを直感的に操作し、 短い時間でも採掘を進められます。
  • iOS / Android 両プラットフォームでの公開に向けて開発中です。

Game loop

運ぶたび、鉱山が大きくなる。

鉱石の運搬、Goldの回収、設備の強化を繰り返し、 より速く、より大きな採掘ラインをつくります。

  1. 押し集める

    散らばった鉱石をブルドーザーでまとめます。

  2. 納品する

    集めた鉱石を納品エリアまで運びます。

  3. トロッコが回収

    積み上がった鉱石が生産ラインを流れます。

  4. Goldを受け取る

    MoneyAreaに貯まったGoldを回収します。

  5. 設備を強化

    採掘力と運搬効率を伸ばし、次の成長へ進みます。

Features

手触りと成長がつながる採掘体験。

01

押して、集めて、運ぶ

物理的に動く鉱石をバケットに抱え、 こぼさないように納品所まで運びます。 一度にたくさん運べたときの手応えが、 そのまま報酬につながります。

02

目に見えるアップグレード

ブルドーザー、鉱山、トロッコ、納品エリアを強化。 新しい鉱石や増えていくトロッコレーンなど、 成長がマップ上の変化として現れます。

9種類の鉱石 最大5レーン 設備強化
03

モンスターで効率化

モンスターを召喚して採掘ラインへ編成。 鉱石運搬、トロッコ加速、鉱石の上位化など、 それぞれの得意な仕事で生産を支えます。

04

離れている間も採掘

条件を達成するとオフライン採掘が解放されます。 ゲームを再開したときに採掘成果を受け取り、 次の設備強化へつなげられます。

Monster helpers

仲間を編成して、生産ラインを育てよう。

モンスターにはそれぞれ異なる役割があります。 鉱山の状態に合わせた編成で、採掘と物流を効率化します。

Offline mining

ゲームを離れている間も、鉱山は動き続ける。

初回のモンスター召喚後はオフライン採掘が解放されます。 再開時に採掘済みの鉱石を受け取り、 すぐに次の強化を始められます。
